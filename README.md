# EvoDental clickable prototype

Open the hosted link, or run locally from this folder.

## Share / view online

**Live prototype:** [https://diksha-kathayat.github.io/evodental-prototype/](https://diksha-kathayat.github.io/evodental-prototype/)

Repo: [https://github.com/diksha-kathayat/evodental-prototype](https://github.com/diksha-kathayat/evodental-prototype)

## Run locally

```bash
npm start
```

Then open [http://localhost:4173](http://localhost:4173).

Or without npm:

```bash
python3 -m http.server 4173
```

Then open [http://localhost:4173](http://localhost:4173).

## Important

Share this **whole folder** (or the repo / hosted URL). Sending only `index.html` breaks local images and scripts.
